# Inventory

Items, containers, equipment slots and the data assets that describe them.

Implemented (vertical slice part 1): the supply types (`ESeminoleSupplyType`, `FSeminoleSupplyAmount`, `FSeminoleSupplyCounts` in `SeminoleSupplyTypes.h`), `USeminoleInventoryComponent` (per-type counts on the player pawn) and `ASeminoleSupplyContainer` (a timed, one-shot lootable crate). Items, slots and data assets are later.
See [docs/ARCHITECTURE.md](../../../docs/ARCHITECTURE.md).
