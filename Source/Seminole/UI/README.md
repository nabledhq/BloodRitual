# UI

HUD and menus. The plan is UMG on CommonUI with widget assets under `Content/UI/`.

Implemented (vertical slice part 1): `ASeminoleHUD`, an `AHUD` that draws the day phase and time remaining, the dusk warning, carried and stockpiled supplies and the interaction prompt with the `Canvas`, so the slice needs no widget assets. It is replaced by the UMG HUD when the UI ticket lands.
